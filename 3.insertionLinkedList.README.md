# 3. Linked List Insertion

## Overview

Is file ka purpose linked list mein naya node insert karna samajhna hai. Teen insertion functions diye gaye hain:

- `insertAtFirst()`
- `insertAtIndex()`
- `insertAtEnd()`

## 1. Beginning par insertion

`insertAtFirst(head, data)` naya node banata hai, uska `next` current head par set karta hai, aur naye node ko head return karta hai.

Example:

```text
Before: 1 -> 2 -> 3 -> NULL
Insert: 0 at first
After:  0 -> 1 -> 2 -> 3 -> NULL
```

## 2. Index par insertion

`insertAtIndex(head, data, index)` list mein specified position par node insert karta hai. Ye previous node tak pahunchkar links ko update karta hai.

Example:

```text
Before: 1 -> 2 -> 3 -> NULL
Insert: 9 at index 1
After:  1 -> 9 -> 2 -> 3 -> NULL
```

Yahan index ko zero-based maana gaya hai.

## 3. End par insertion

`insertAtEnd(head, data)` last node tak traverse karta hai. Last node ke `next` mein naye node ka address store karta hai, aur naye node ka `next` `NULL` rakhta hai.

Example:

```text
Before: 1 -> 2 -> 3 -> NULL
Insert: 4 at end
After:  1 -> 2 -> 3 -> 4 -> NULL
```

## Current code ka important note

File mein structure `struct node` ke naam se define hai, lekin insertion functions mein `struct Node` use hua hai. C mein uppercase aur lowercase alag hote hain. Compile karne ke liye function declarations mein `struct Node` ko `struct node` karna hoga.

## Compile aur run

Correction ke baad:

```powershell
gcc 3.insertionLinkedList.c -o insertion.exe
.\insertion.exe
```

Current `main()` insertion functions ko call nahi karta; woh sirf original list traverse karta hai.
