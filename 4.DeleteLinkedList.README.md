# 4. Linked List Deletion

## Overview

Is file mein linked list se node delete karne ke methods diye gaye hain:

- `DeleteFirst()` - first node delete karta hai
- `deleteAtLast()` - last node delete karta hai
- `deleteAtIndex()` - given index par node delete karta hai

## 1. First node delete karna

`DeleteFirst(head)` current head ko temporary pointer mein save karta hai. Phir head ko next node par move karke old node ko `free()` karta hai.

Example:

```text
Before: 10 -> 40 -> 30 -> NULL
Delete first
After:  40 -> 30 -> NULL
```

## 2. Last node delete karna

`deleteAtLast()` do pointers use karta hai: `p` previous node ke liye aur `q` current node ke liye. Jab `q` last node par pahunchta hai, `p->next` ko `NULL` karke `q` ko free kar diya jaata hai.

## 3. Index par deletion

`deleteAtIndex(head, index)` previous node tak jaata hai, target node ko list se unlink karta hai, aur memory release karne ke liye `free()` use karta hai.

Example:

```text
Before: 10 -> 40 -> 30 -> NULL
Delete index 1
After:  10 -> 30 -> NULL
```

## Current code ke important notes

- Structure ka naam `struct node` hai, lekin do functions mein `struct Node` likha hai. Dono jagah `struct node` same case mein use karna hoga.
- `traversal(head)` ke baad semicolon missing hai. Us line ko `traversal(head);` karna hoga.
- Empty list aur single-node list ke edge cases ke liye extra checks add karna useful hoga.
