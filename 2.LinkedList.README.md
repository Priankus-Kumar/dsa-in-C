# 2. Singly Linked List Traversal

## Overview

Is file mein ek singly linked list banayi gayi hai aur uske elements ko traverse karke print kiya gaya hai.

Linked list mein har node ke do parts hote hain:

1. `data`: actual value
2. `next`: next node ka address

## Code kaise kaam karta hai

`struct node` ek node ka structure define karta hai. `malloc()` se memory mein teen nodes banaye jaate hain: `head`, `second`, aur `third`.

Links is tarah connect hote hain:

```text
head(1) -> second(2) -> third(3) -> NULL
```

`linkedListTraversal()` head se start karta hai. Jab tak pointer `NULL` nahi hota, tab tak data print hota hai aur pointer next node par chala jaata hai.

## Example output

```text
Hello World
Element: 1
Element: 2
Element: 3
```

## Compile aur run

```powershell
gcc 2.LinkedList.c -o linkedlist.exe
.\linkedlist.exe
```

## Important point

`NULL` linked list ka end show karta hai. Traversal ke time pointer ko next node par move karna zaroori hai, warna loop infinite ho sakta hai.
