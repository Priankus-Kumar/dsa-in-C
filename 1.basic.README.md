# 1. Basic C Program

## Overview

Ye sabse basic C program hai. Iska purpose screen par `Hello World` print karna hai. C programming start karte waqt usually isi type ke program se shuruaat hoti hai.

## Code kaise kaam karta hai

- `#include <stdio.h>` se standard input-output library include hoti hai.
- `main()` program ka starting point hota hai.
- `printf("Hello World");` text ko console par print karta hai.
- `return 0;` batata hai ki program successfully complete hua.

## Example

Program run karne par output hoga:

```text
Hello World
```

## Compile aur run

```bash
gcc 1.basic.c -o basic
./basic
```

Windows PowerShell mein executable run karne ke liye:

```powershell
gcc 1.basic.c -o basic.exe
.\basic.exe
```

## Seekhne wali baat

Har C program mein normally `main()` function hota hai. Execution `main()` se start hoti hai.
