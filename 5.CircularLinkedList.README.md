# 5. Circular Linked List

## Overview

Circular linked list mein last node ka `next` `NULL` nahi hota. Woh dobara first node, yani `head`, ko point karta hai.

Is file mein paanch nodes ki circular linked list banayi gayi hai:

```text
5 -> 4 -> 3 -> 2 -> 1
^                   |
|___________________|
```

## Code kaise kaam karta hai

- `struct node` mein data aur next pointer define hai.
- `malloc()` se paanch nodes ke liye memory allocate hoti hai.
- Har node ko next node se connect kiya jaata hai.
- Fifth node ka `next = head` set kiya gaya hai, isliye list circular ban jaati hai.

## Traversal

`CircularTraversal()` `head` se start karta hai aur `do-while` loop use karta hai. Pehle current node print hota hai, phir pointer next node par move hota hai. Jab pointer wapas `head` par aa jaata hai, loop stop ho jaata hai.

Circular list ke liye normal `while(ptr != NULL)` use nahi kar sakte, kyunki pointer kabhi `NULL` tak nahi pahunchta.

## Example output

```text
Element:5
Element:4
Element:3
Element:2
Element:1
```

## Compile aur run

```powershell
gcc 5.CircularLinkedList.c -o circular.exe
.\circular.exe
```

## Real-life use

Circular linked list ka use round-robin scheduling, playlist looping, aur circular queue jaise cases mein kiya ja sakta hai.
